## 4. 现实约束（这些不会因为努力而消失）

- **设备**：可用内存约 3.5 GB，Docker Desktop 启动会很吃力 → W8 前评估「本地跑代码 + 云主机跑容器」方案
- **显卡**：MX350 2GB，跑不了本地大模型，全部走云 API，别在 Ollama 上浪费时间
- **网络**：OpenAI、HuggingFace 直连不通 → 模型走 DeepSeek / 百炼 / 智谱 / Moonshot；embedding 模型走 ModelScope 或 hf-mirror
- **PowerShell 执行策略 Restricted** → 不激活 venv，直接用 `.\.venv\Scripts\python.exe`

## 5. 三个月后必须能做到（可验收，不含"了解""熟悉"）

- **M0（2026-12-27）**：不看教程，从零写出一个 Agent——3 个工具、Pydantic 参数校验、最大步数、超时、重试、预算上限；20 例评测成功率 ≥80%
