## 学到的概念

1. **虚拟环境按项目分，不按周分，更不装全局**
   - 是什么：每个项目根目录一个 `.venv`，依赖装在自己里面，项目之间互不可见
   - 为什么需要：`chromadb`、`langgraph` 这类包会互相拆对方依赖的版本；全局装一遍，出问题时根本分不清是谁干的
   - 什么时候用：只要是"要进 git、要写 README、要给别人跑"的项目，就必须独立
   - 粒度判断：一个独立仓库 = 一个 venv。全局解释器只放 pip/uv 这类工具

2. **git 的三个区**
   - 工作区（改了的文件）→ 暂存区（`git add` 之后）→ 历史（`git commit` 之后）
   - 为什么需要暂存区：它让你**在提交前有机会反悔**，比如发现 `.env` 被加进来了还能撤

3. **`.gitignore` 是唯一挡在密钥和公网之间的东西**
   - 一旦 `.env` 被 push 上去，删掉文件也没用——提交历史里永远留着，只能去平台撤销重发 key

4. **编辑器飘红 ≠ 代码有错**
   - 飘红的来源有三个，要分清：语言服务器（Pylance）找不到包、第三方插件自己的分析器、语法错误
   - 判断顺序：先看用什么解释器，再看有没有装语言服务器，最后才怀疑代码

## 踩的坑

### 坑 1：代码飘红，误以为是"中文路径 + 空格"导致的
- **现象**：`from openai import OpenAI` 报"无法解析导入"
- **原因**：两个叠加。① `code\.venv` 是个残缺目录，只有 `Scripts\` 没有 `pyvenv.cfg`，Python 自己都不认；② **VS Code 根本没装 Python 扩展**，没有语言服务器，也没有解释器选择功能
- **解法**：删掉残缺 venv；装 `ms-python.python` + `ms-python.vscode-pylance`；手动 Select Interpreter 指向剩下那个合法 venv
- **下次怎么避免**：新环境第一步先 `code --list-extensions` 确认扩展齐了。遇到"路径问题"的猜测，先用 Python 在那个路径下跑一次导入验证，别凭感觉

### 坑 2：pip install 在沙箱里报 `WinError 5`
- **现象**：`PermissionError: [WinError 5] ... sandbox-center-runtime-kit\shim`
- **原因**：运行环境给每个 Python 进程注入了 `PYTHONPATH`，指向一个无权访问的目录，pip 扫描包时崩
- **解法**：`python -E`（忽略所有 `PYTHON*` 环境变量）+ `--no-cache-dir`
- **下次怎么避免**：这是这个工具环境特有的，自己开 PowerShell 不会遇到

### 坑 3：VS Code 自动生成的嵌套 `.vscode/settings.json` 路径是错的
- **现象**：选完解释器后，子目录里多出一份配置，写着 `${workspaceFolder}/.venv/...`
- **原因**：`${workspaceFolder}` 指打开的那个根目录，所以会解析成 `<根目录>/.venv/...`——不存在
- **解法**：删掉，统一用根目录那份配置；`.gitignore` 加 `code/**/.vscode/`

### 坑 4：百炼 429 `limit_requests`
- **现象**：`openai.RateLimitError: 429 ... code: 'limit_requests'`
- **原因**：免费额度下请求频率限制极严（不是 key 错，也不是欠费）
- **解法**：等几分钟重试；后来自然恢复
- **下次怎么避免**：看到 429 先判断是限流还是额度耗尽——`401` 才是 key 错，`insufficient_quota` 才是欠费

### 第一版实测数据

| 供应商 | 模型 | 中位延迟 | tokens（入+出） | 1000 次成本 |
|---|---|---|---|---|
| 百炼 | qwen3.8-flash | 4.59s | 98+378 | ¥1.10 |
| DeepSeek | deepseek-chat | 1.41s | 42+105 | ¥0.92 |

### 从这组数字里学到的三件事（比数字本身重要）

1. **同一句中文，两家切出的 token 数差 2.3 倍**（98 vs 42）
   - tokenizer 不同。标价便宜 ≠ 花得少——喂同样的话，切得碎的那家要多算 token
2. **"1000 次成本"不能直接横比**
   - DeepSeek 的 0.92 元更低，纯粹因为它只写了 105 token（百炼写了 378）
   - 按"每千输出 token"比，百炼 ¥0.0027 vs DeepSeek ¥0.0080，**百炼便宜 3 倍**
   - 教训：比价格用单价，不用总价
3. **总延迟 4.59 vs 1.41 是假象**
   - 换成生成速度：378÷4.59=**82 tok/s** vs 105÷1.41=**74 tok/s**，真实差距约 10%
   - 教训：比速度用 tok/s，不用总延迟

### 手算成本（不用代码，建立直觉）

- 单次：(42×2 + 105×8) ÷ 100万 = **¥0.00092**
- 每天 500 次 × 30 天 = 15,000 次 → **¥13.86/月，每天不到 5 毛**
- 输出涨到 400 token（3.8 倍）→ 成本涨 **3.55 倍**，因为输入部分被摊薄
- 结论：这个阶段成本不是瓶颈，真正贵的是自己的时间
