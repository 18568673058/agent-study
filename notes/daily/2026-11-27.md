## 一句话

从"会调 API"跨到"会做交互"：搞懂了流式的三个时间点、模型的记忆其实是我自己维护的 messages 列表，以及上下文截断为什么必须按整轮切。

## 学到的概念

1. **流式的本质：返回的不是响应，是迭代器**
   - `stream=True` 时 `create()` 返回的是一个"水管"，数据还没生成
   - 非流式返回成品，流式返回还没生产完的东西——这个区别解释了后面所有的坑
   - 一行 `print(response)` 就能看出来：`<openai.Stream object at 0x...>`

2. **三个时间点，不是一个**
   - `t0` 请求前 → `t1` 第一个非空字 → `t2` 最后一个字
   - **首字延迟 = t1 - t0**（用户体感）；**生成速度 = completion_tokens / (t2 - t1)**（模型能力）
   - 我之前把 t0 放在 `create()` 后面，漏掉了建连接的时间，首字延迟被低估

3. **模型是无状态的，"记忆"是我的 messages 列表**
   - 第 N 轮的请求里包含前 N-1 轮的全部内容
   - 代价是平方级：聊 10 轮，总 token 约 55 倍（1+2+…+10）
   - 所以上下文截断不是优化，是必须

4. **各家的"OpenAI 兼容"只兼容形状，不兼容细节**
   - usage 的位置不一样：OpenAI 官方单独一个空 choices 的包，DeepSeek 挂在带 `finish_reason` 的包上
   - 所以要在每个包里都查一次 `chunk.usage`，不能假设某个特定包才有

5. **prompt token 不能按字数折算**
   - 同一句 8 字请求：百炼 65 token，DeepSeek 18 token，差 3.6 倍
   - 跨平台比成本必须用同一请求实测

## 踩的坑

> 今天在一个功能点上改了四轮，四个坑全是真实项目里的高频事故。

### 坑 1：计时放在循环内部
- **现象**：每轮耗时都是 0.00s
- **原因**：`start_time = time.time()` 和 `end_time = time.time()` 之间只隔一句 `print`，测的是"打印一行字的时间"
- **正确做法**：三个时间点写在三个不同位置——t0 循环前、t1 循环内只记第一次、t2 循环后

### 坑 2：`t0` 放在 `create()` 之后
- **现象**：首字延迟偏小
- **原因**：`create()` 会等 TLS 握手和响应头，这 0.3–0.8s 被漏掉了
- **规则**：计时的起点必须在请求发出之前

### 坑 3：一个变量既存"片段"又存"全文"
- **现象**：屏幕上是 `你你好你好！你好！很...` 越滚越长
- **原因**：`content += piece` 后 `print(content)`，打印的是累积值
- **正确做法**：`piece` 用于打印，`full` 用于累加，两个变量

### 坑 4（最难）：影子副本不同步，记忆完全失效
- **现象**：每轮 messages 都只剩 `[system, user, assistant]`，history 永远是 0
- **原因**：`history = messages[1:]` 在循环顶部重新算（或初始化后从不更新），`messages = [system] + history` 每轮把上一轮内容覆盖掉
- **正确做法**：**不要保存影子副本**。每轮从 `messages` 现算：
  ```
  history = messages[1:]
  if len(history) > KEEP_ROUNDS * 2:
      history = history[-KEEP_ROUNDS * 2:]
  messages = [messages[0]] + history
  ```
- **教训**：两份状态 = 必然分叉，且不报错

### 坑 5：截断切掉 system prompt
- **现象**：聊到第 12 轮，人设突然失效，回答变啰嗦，但没有任何报错
- **原因**：`messages[-10:]` 把 `messages[0]`（system）一起切了
- **规则**：**system 永远单独保留**，只从 `messages[1:]` 下手

### 坑 6：判断用"轮"、截取用"条"
- **现象**：以为保留 10 轮，实际只留 6 轮
- **原因**：`if (len-1)/2 > 10` 判轮数，`messages[-10:]` 截条数，1 轮 = 2 条
- **规则**：`KEEP_ROUNDS * 2`，判断和截取用同一单位

### 坑 7：文件头 docstring 没改
- **现象**：`chat_multi.py` 的文件头写着"跑法：python chat_stream.py"
- **后果**：不报错，但三个月后自己打开会以为拿错文件
- **规则**：新建文件第一件事写文件头（干什么 / 怎么跑 / 有哪些坑）；复制文件时**先改文件头再改代码**
